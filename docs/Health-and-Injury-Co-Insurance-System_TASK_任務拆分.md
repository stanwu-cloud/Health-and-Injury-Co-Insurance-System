## 2. 背景與目的

將 DESIGN 之模組切分轉換為可指派、可驗收的開發任務，明確標示前置依賴、預期輸出、驗收條件、風險與優先級。

**優先級定義**：P0 = 阻擋後續任務；P1 = 核心功能；P2 = 必要但可後做；P3 = 加值。
