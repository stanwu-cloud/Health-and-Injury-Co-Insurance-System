## 2. 背景與目的

### 2.1 為何建立此文件

專案目標為產出「當月共保月帳單」報表程式（T 字帳、彙總表兩張）。目前 `docs/` 下已有兩份規格書（v1.0）、一份設定檔範例、兩份 Excel 樣板、兩份產出範例，以及一組實際 CSV 匯入檔（115 年 5 月）。

本文件將上述資產逐一盤點、實際開啟驗證，建立「已確認事實」基線，作為後續 MAPPING / RULE / REQ / DESIGN 的唯一依據。

### 2.2 解決什麼問題

- 釐清規格書文字描述與實體樣板／範例檔之間的一致性
- 建立輸入（CSV、設定檔、樣板）與輸出（兩張 xlsx）的完整清單
- 以實際資料驗算範例報表數字，確認業務規則可被程式重現

### 2.3 適用範圍

適用於「當月共保月帳單-T 字帳」與「當月共保月帳單-彙總表」兩張報表之開發。不含其他報表、不含資料上傳／前端介面。
