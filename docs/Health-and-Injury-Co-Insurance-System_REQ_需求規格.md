## 2. 背景與目的

### 2.1 為何建立此文件

「執行災害防救業務志工團體保險共保組織」每月需向共保成員產出兩張月帳單報表。目前作業以人工開啟 Excel 彙整 CSV 匯入檔完成，耗時且易因四捨五入順序、公司成分對應等細節產生帳差。

本文件定義自動化程式之完整需求，作為 DESIGN、TASK、TEST 之唯一需求來源。

### 2.2 解決什麼問題

| # | 現行痛點 | 本系統之對應 |
| --- | --- | --- |
| 1 | 匯入檔欄位錯誤需人工逐筆檢查 | 全欄位自動檢核，一次列出所有錯誤 |
| 2 | 共保成分表散落於多份文件，易不同步 | 統一由 `config/application.xlsx` 驅動，並檢核合計 = 100% |
| 3 | 分攤金額之四捨五入順序易錯，導致帳差 | 以明確規則實作（先逐家四捨五入、再乘 6%、再四捨五入、最後加總） |
| 4 | 兩張報表數字需人工核對一致 | 程式內建跨報表一致性檢查 |
| 5 | 覆蓋舊報表後無法回溯 | 產出前自動備份，保留 3 個月 |

### 2.3 適用範圍

**包含**：「當月共保月帳單-T 字帳」與「當月共保月帳單-彙整表」兩張報表之產製。

**不包含**：其他共保報表、資料上傳介面、匯入檔之產生（由共保系統另行匯出）、報表寄送／簽核流程、資料庫儲存。

## 3. 使用情境

### UC-01 每月例行產製（主要情境）

| 項目 | 內容 |
| --- | --- |
| 觸發者 | 共保業務承辦人員 |
| 前置條件 | 共保系統已匯出當月保費／理賠 CSV，並置於 `./input/{YYYMM}/`；`./config/application.xlsx` 之設定年月已更新 |
| 主要流程 | 1. 承辦人員雙擊 fat jar 開啟 GUI（或執行 `拜託執行我.bat`，該批次檔已併入編譯步驟）<br>2. 確認／指定處理年月<br>3. 觸發執行<br>4. 程式讀設定檔 → 檢核匯入檔 → 計算 → 產出 **T 字帳、彙整表，以及每個非當年度簽單年度各一份賠款 T 字帳與一份賠款彙總表**<br>5. 承辦人員於 `./output/{YYYMM}/` 取得全部報表 |
| 後置條件 | **2 + N×2 份** xlsx 產出（N = 非設定年之簽單年度數；樣本 115/5 → N = 2，共 **6 份**）；`./logs/report.json` 記錄本次執行結果<br>**本用例以保費檔存在為前提**；保費檔缺檔時為 **0 + N′×2 份**（N′ 含設定年），見 UC-07 |
| 例外分支 | 檢核失敗 → 見 UC-02；保費檔缺檔 → 見 UC-04 與 **UC-07**；無非當年度簽單資料 → 見 **UC-06** |

### UC-02 匯入檔檢核失敗

| 項目 | 內容 |
| --- | --- |
| 觸發條件 | 任一匯入檔欄位不符檢核規則 |
| 流程 | 1. 程式收集**全部**錯誤（不於第一筆中止）<br>2. 錯誤訊息輸出至主控台、日誌檔、`report.json`；GUI 模式另於畫面表格列出<br>3. **全部報表皆不產出（四種報表同進退）** |
| 錯誤訊息內容 | 檔名、行號、欄位名稱、實際值、違反之規則 |
| 後續 | 承辦人員請共保系統修正匯入檔後重跑 |

### UC-03 當月無理賠資料

| 項目 | 內容 |
| --- | --- |
| 觸發條件 | `./input/{YYYMM}/VOLC{YYYMM}.csv` 不存在 |
| 流程 | **不視為錯誤**；所有理賠相關參數以 `0` 計算；**T 字帳與彙整表正常產出**，賠款相關欄位以 `-` 顯示；**賠款 T 字帳與賠款彙總表皆不產出任何份數**（無資料可分年），整體仍視為執行成功 |

### UC-04 前置資源缺漏

| 觸發條件 | 行為 |
| --- | --- |
| 保費檔不存在 | **前兩張報表不產出、兩張賠款報表照常產出**（見 UC-07）；若兩張賠款報表亦為 0 份 → 錯誤中止，不產出任何檔案 |
| 設定檔不存在／格式錯誤 | 錯誤中止 |
| 共保成分合計 ≠ 100% | 錯誤中止 |
| 樣板檔不存在 | 錯誤中止 |
| 樣板公司名稱查無設定檔對應 | 錯誤中止，回報該列號與名稱 |
| 備份既有輸出檔失敗 | 錯誤中止，**不覆寫原檔** |

### UC-05 重跑同一年月

| 項目 | 內容 |
| --- | --- |
| 觸發條件 | `./output/{YYYMM}/` 已有同名報表 |
| 流程 | 產出前先將既有檔移至 `./backup/{YYYMM}/{yyyyMMddHHmmss}/`，再寫入新檔；同時清除超過 3 個月之舊備份 |
| 備註 | **賠款 T 字帳與賠款彙總表之各 N 份輸出同樣納入備份**；若本次之年度組合與前次不同（例：上月有 113 年、本月無），前次之 113 年檔（**兩張都會**）會留在 output 目錄不被覆寫 —— 此為**已知現象**，見 §11 |

### UC-06 當月無「非當年度」簽單資料（第二階段）

| 項目 | 內容 |
| --- | --- |
| 觸發者 | 共保業務承辦人員 |
| 觸發條件 | **保費檔存在**、理賠檔存在且檢核通過，但**全部簽單年度皆等於設定年**（例：設定年 115，理賠資料全為 115 年簽單） |
| 流程 | 1. T 字帳與彙整表**正常產出**<br>2. **賠款 T 字帳與賠款彙總表皆產出 0 份**——設定年之賠款已由第一階段之「攤付共保賠款」承載<br>3. 主控台、`report.json` 與 GUI 明確顯示「無非當年度簽單資料，未產出賠款月帳單」 |
| 後置條件 | **視為執行成功（exit code 0）**；`report.json` 之產出清單僅含前兩張報表 |
| 備註 | 這是**正常業務狀態，不是錯誤**。理賠檔缺檔（UC-03）之結果相同，但原因不同，訊息須可區分<br>**本情境以「保費檔存在」為前提**：若保費檔缺檔，設定年**不會**被排除，改走 UC-07 產出設定年 1 份 |

### UC-07 當月無保費資料（第二階段，P-12）

| 項目 | 內容 |
| --- | --- |
| 觸發者 | 共保業務承辦人員 |
| 觸發條件 | `./input/{YYYMM}/VOLP{YYYMM}.csv` **不存在**，但理賠檔存在且有資料 |
| 流程 | 1. **T 字帳與彙整表不產出**（兩張同進退）<br>2. **賠款 T 字帳與賠款彙總表照常產出**——兩張只讀理賠檔，不依賴保費檔<br>3. **設定年不被排除**（BR-16）：前兩張沒產出，設定年之賠款改由這兩張承載，**每個簽單年度各一份 T 字帳 + 一份彙總表**<br>4. 主控台、`report.json` 與 GUI 顯示「未產出共保月帳單：保費匯入檔不存在」，並警示保費／管理費／Balance Due 均以 0 計算、**非本月實際金額** |
| 後置條件 | **視為執行成功（exit code 0）**；`report.json` 之 `premiumFileMissing` 為 `true`，產出清單僅含兩張賠款報表。樣本（115/5、理賠檔含 115／114／113）產出 **6 份**（3 年度 × 2 張）：115 → 126,931、114 → 38,331、113 → 32,460，合計 197,722 = 理賠檔全部已決賠款 |
| 例外分支 | 兩張賠款報表仍為 0 份（理賠檔亦缺檔或無資料列）→ **四張全部落空** → **錯誤中止（exit code 2）**，中止訊息須指出是哪一種原因 |
| 備份 | 本次不重寫之前兩張報表**不得**被移入備份目錄——移走卻不補回會使承辦人員誤以為前次成果遺失 |
| 備註 | **「缺檔」與「空檔」不同**：保費檔存在但只有表頭（0 資料列）不適用本情境，走 UC-01 正常流程，三張報表照產、保費相關金額為 0、Balance Due 為負值照實寫入 |

## 5. 輸入規格

### 5.1 輸入清單

| # | 輸入 | 路徑 | 必要性 | 格式 |
| --- | --- | --- | --- | --- |
| I1 | 保費匯入檔 | `./input/{YYYMM}/VOLP{YYYMM}.csv` | **必要** | Big5/CP950、逗號分隔、含表頭、19 欄 |
| I2 | 理賠匯入檔 | `./input/{YYYMM}/VOLC{YYYMM}.csv` | 選用 | Big5/CP950、逗號分隔、含表頭、22 欄 |
| I3 | 設定檔 | `./config/application.xlsx` | **必要** | xlsx，工作表 `工作表1` |
| I4 | T 字帳樣板 | `./templet/PREMIUM_T_ACCOUNT.xlsx` | **必要** | xlsx，工作表 `工作表1` |
| I5 | 彙整表樣板 | `./templet/PREMIUM_SUMMARY.xlsx` | **必要** | xlsx，工作表 `工作表2` |
| I6 | 命令列參數 | `--year` / `--month` | 選用 | 覆寫設定檔年月 |

`{YYYMM}` = 民國年（3 碼）+ 月份（**補零 2 碼**），例：115 年 5 月 → `11505`。

### 5.2 欄位規格

完整欄位對照（含索引、型別、必填、轉換與驗證規則）見 **`..._MAPPING_欄位對照.md` §3～§5**。本節僅列關鍵約束：

| # | 約束 | 說明 |
| --- | --- | --- |
| A1 | 編碼固定 Big5 | 不做編碼偵測 |
| A2 | 固定含表頭列，且須驗證表頭內容 | 欄位名稱與順序須與預期清單完全一致，不符即中止 |
| A3 | **以位置索引讀取欄位** | 兩檔皆有重複欄名「日額」，不可依名稱取值 |
| A4 | 保費檔唯一參與計算之金額欄 | 索引 17「保費合計」（**可為負值**，批單沖銷） |
| A5 | 理賠檔唯一參與計算之金額欄 | 索引 21「已決賠款 合計」 |
| A6 | 理賠檔核心篩選欄 | 索引 5「簽單年度」 |
| A7 | 匯入檔帳單年月須等於設定檔年月 | 以**數值**比對 |
| A8 | 不去重、不檢核重複 | 相同保單號碼／賠案號碼之多列全部計入 |

### 5.3 設定檔規格

| 儲存格 | 內容 | 約束 |
| --- | --- | --- |
| B1 | 設定年（民國） | >= 103 |
| B2 | 設定月 | 1–12 |
| A6 起 | 公司名稱 / 公司代號 / 認受成分 | **動態讀取至第一個空白列**；名稱與代號不可重複；**成分合計須等於 100%** |

現行內容為 16 家（見 現況分析 §4.3）。中央再保之公司代號固定為 `N19`。

### 6.4 賠款 T 字帳輸出欄位（第二階段）

> **❗儲存格語意與 §6.2 之 T 字帳不同**，程式須另立常數類別，不得共用。五處落差已於下表「§6.2 同格用途」欄標出。

| 2 | U/Y 標籤 | O4 | 樣板既有 `U/Y:`，**不寫入** | 同 |
| 3 | U/Y 年 | P4 | **該份報表之簽單年度 + 1911** | ❗設定年 + 1911 |
| 4 | 攤付共保賠款 | G6 | 該簽單年度之「已決賠款合計」總和 | 設定年之賠款合計 |

| # | 欄位 | 位置 | 內容 | §6.3 同欄用途 |
| --- | --- | --- | --- | --- |
| 1 | U/Y | A3 | `Ｕ/Y：{該份報表之簽單年度 + 1911}`（全形Ｕ與全形冒號） | ❗**設定年** + 1911 |

### 6.7 執行報告（report.json）

## 7. 業務規則

完整規則（含計算式、樣本驗算值、證據等級）見 **`..._RULE_規則定義.md`**。本節列出需求層級之核心規則：

| 規則 | 內容 | 對應 |
| --- | --- | --- |
| BR-01 | 共保保費 = 保費檔全部「保費合計」加總（含負值） | R-CALC-01 |
| BR-02 | 攤付共保賠款 = 理賠檔篩「簽單年度 = 設定年」之「已決賠款合計」加總（**僅篩年、不篩月**） | R-CALC-03 |
| BR-03 | 各公司應分配保費：非中央再保 = `ROUND(總保費 × 成分)`；**中央再保 = 總保費 − 其餘公司加總（差額法）** | R-CALC-05 |
| BR-04 | 各公司應攤配賠款：同 BR-03 之邏輯，基礎改為賠款總額 | R-CALC-06 |
| BR-05 | 共保管理費 = Σ`ROUND(各公司分攤保費 × 6%)`。**先逐家四捨五入 → 再乘 6% → 再四捨五入 → 最後加總**，順序不可調換 | R-CALC-07 |
| BR-06 | 應繳共保管理會費（列層級）= `ROUND(應分配保費 × 6% × (−1))`，因應分配保費為負，結果為**正值** | R-CALC-08 |
| BR-07 | Balance Due = 共保保費 − 攤付共保賠款 − 共保管理費；**為負時照實填入負數，不得留空或轉為 0** | R-CALC-13 |
| BR-08 | T 字帳 G21 與 O21 **直接等於共保保費**，非欄位加總 | R-CALC-14 |
| BR-09 | 中央再保**依公司代號 `N19` 判定**，不依列號 | R-CALC-05 |
| BR-10 | 所有四捨五入採 **HALF_UP**（半數進位、遠離 0），不可使用 HALF_EVEN | 全域約定 |
| BR-11 | 西元年 = 民國年 + 1911 | R-CALC-15 |
| BR-12 | 跨報表一致性：T 字帳 G6 = 彙整表 C23、O6 = B23、G14 = I23 | R-CALC-16 |
| BR-13 | 彙整表列順序以樣板 A 欄為準，依**公司名稱**對應設定檔之代號與成分 | R-OUT-02 |
| BR-14 | 共保成分合計須等於 100% | R-PATH-01 |

**第二階段（賠款 T 字帳）之業務規則**：

| 規則 | 內容 | 對應 |
| --- | --- | --- |
| BR-15 | 依理賠檔之**簽單年度**分群加總「已決賠款合計」，**全年度皆計、不篩選** | R-CALC-17 |

**第二階段·第四張報表（賠款彙總表）之業務規則**：

| 規則 | 內容 | 對應 |
| --- | --- | --- |
| **BR-24** | 賠款彙總表與賠款 T 字帳**共用同一份年度清單**（BR-16），份數、年度與是否產出**永遠一致**；一次執行之產出為（保費檔存在 ? 2 : 0）+ N×2 檔 | R-PATH-08、R-RUN-03 |

| **BR-26** | `B`（保費）、`F`（應分配保費）、`I`（管理會費）三欄**恆為數值 0**（含合計列）——本報表不讀保費匯入檔 | R-CALC-22 |
| **BR-27** | **零和不變式**：每份賠款彙總表之合計列 `J23` **恆為 0**（`ΣJ = −ΣC + ΣG`，而 `ΣG ≡ ΣC`）。於執行期驗證，不成立即視為程式缺陷並中止 | R-CALC-24 |
| **BR-28** | 賠款彙總表之 `A3` 西元年 = **該份之簽單年度** + 1911（**非設定年**）；`E3` 仍取設定檔年月 | R-CALC-23 |
| **BR-29** | `C` 欄取**該份報表之簽單年度**（**非設定年**）——若取設定年，各年度報表內容將完全相同而失去意義 | R-CALC-21、R-CALC-22 |
| **BR-30** | `G` 欄（應攤配賠款）之分攤基準為**該年度合計**（`C23`）乘成分，**與各公司自身之賠款金額無關**；中央再保仍為差額法（BR-03 / BR-09） | R-CALC-22 |
| **BR-31** | `J` 欄 = `D + H + I`（依範本公式），**非**規格書文字之「五項相加」——後者漏了已付賠款之負號 | R-CALC-22 |
| **BR-32** | 跨報表不變式：同年度之彙總表 `C23` = 賠款 T 字帳 `G6`；彙總表 `A3` 之西元年 = 賠款 T 字帳 `P4` | R-CALC-16 |
