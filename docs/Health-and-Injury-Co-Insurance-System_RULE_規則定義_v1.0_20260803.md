## 2. 背景與目的

將兩份規格書之文字敘述，轉換為可實作、可測試的規則條目，並標示與範例檔實測結果之一致／矛盾狀態。

**規則編號體系**：
- `R-PATH-xx` 路徑與檔名規則
- `R-VAL-xx` 匯入檔檢核規則
- `R-CALC-xx` 計算規則
- `R-OUT-xx` 輸出寫入規則
- `R-EXC-xx` 例外處理規則

**證據等級標示**：
- 【文件明載】規格書明文載明
- 【原始碼可證】以實體檔案／樣本資料驗證成立
- 【合理推論】由範例反推
- 【待確認】存在矛盾，需業務方裁決

| 例外情境 | 理賠檔不存在 → 全部 0 |
| 優先順序 | 7 |
| 證據等級 | 【文件明載】彙總表規格第 8 項；【原始碼可證】 |
| 測試案例 | TC-R-CALC-06 |

### R-CALC-07 共保管理費

| 項目 | 內容 |
| --- | --- |
| 規則名稱 | 共保管理費（T 字帳 G14 / 彙總表 I 欄與 I23） |
| 輸入條件 | R-CALC-05 之各公司**正值**分攤保費 |
| 處理邏輯 | 1. 先計算保費匯入檔 **[保費合計]** 總金額<br>2. 各共保公司（**不含中央再保**）分攤保費 = 總保費 × 共保成分，四捨五入至整數<br>3. 中央再保分攤保費 = 總保費 − Σ(其他公司分攤保費)<br>4. 各公司（**含中央再保**）管理費 = 分攤保費 × 5%，四捨五入至整數<br>5. 共保管理費總額 = Σ 各公司管理費 |

| 測試案例 | TC-R-CALC-07 |
| 備註 | **重要**：先對「各公司分攤保費」四捨五入，再乘 5% 後**再次四捨五入**，最後才加總。順序不可調換，否則結果不同 |
