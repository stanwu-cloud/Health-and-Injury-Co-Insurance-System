## 5. 推論事項

| # | 推論內容 | 依據 |
| --- | --- | --- |
| P1 | 【推論】依 A-01 / A-02 / A-24「以設定檔為準」，程式應**由設定檔動態產生彙總表明細列**（含將公司名稱寫入 A 欄），而非沿用樣板預填之名稱 | A-24「以設定檔為主」隱含動態；且設定檔已含公司名稱欄 |
| P2 | 【推論】中央再保應**依公司代號 `N19` 判定**，而非依「最後一列」判定 | 設定檔中 N19 位於第 9 順位，若依列號判定將取到錯誤公司 |
| P3 | 【推論】設定檔中央再保之 12% 疑為誤植，正確值應為 **7%** | 其餘 15 家合計 93%，差額法推得 7%；舊範例檔中央再保亦為 7% |
| P4 | 【推論】A-09「1 → 01」係要求**程式將設定檔月份補零後組成 YYYMM**，而非要求匯入檔內容改為 `05` | 匯入檔為外部系統產出，不受本程式控制；且 A-11 要求年月比對，以**數值**比對即可 |
| P5 | 【推論】A-16「直接複寫原來檔案備份到備份文件夾中」= 產出前先將既有同名檔移至備份目錄，再寫入新檔 | 依中文語序解讀 |
| P6 | 【推論】備份目錄建議為 `./output/{YYYMM}/backup/{yyyyMMddHHmmss}/` | A-16 未指定路徑 |
| P7 | 【推論】技術堆疊採 Java 17 + Spring Boot + Apache POI，沿用 `retained-premium-report-transformer` 分層架構；GUI 以 JavaFX 或 Swing 包裝同一核心服務 | A-19「參考其他專案方式」+「命令列批次跟圖形介面都要」 |
