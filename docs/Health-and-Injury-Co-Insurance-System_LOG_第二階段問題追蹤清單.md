## 2. 背景與目的

第二階段新增第三張報表「**當月賠款月帳單－T字帳**」：以理賠匯入檔為唯一資料來源，**排除設定年之簽單年度**，其餘每個簽單年度各產出一份報表。

本文件在動工前先列出規格書 v1.0 與實體樣板／範例檔之間的**矛盾與缺口**，供業務方逐項確認。依 CLAUDE.md「資訊不足時先產出待確認問題清單，不得逕行產出設計與程式碼」之規定，**P-01 ~ P-04 未結案前不進入 MAPPING / RULE / 實作**。

### P-01 資料統計年月：`I3` 單格 vs `I3` + `J3` 兩格 ｜ 🔴 阻斷

**矛盾**：

| 來源 | 內容 |
| --- | --- |
| 規格書 v1.0 輸出表 項次 1 | `資料統計年月 | I3 | 民國年_設定檔年月` → 讀來是**單格** |
| 兩份產出範例檔（實測） | `I3` = `115 年`、`J3` = ` 05 月` → **兩格** |
| 範例圖檔 1 標記 ① | 框住「資料統計年月： 115 年  05 月」整段，無法判別格數 |
| **第一階段已定案** | **N-04 / B06：改為單格 `I3` = `115 年 05 月`，月份補零** |

**分析**：第二階段兩份範例檔之版面（`I3`+`J3` 兩格、`O4` = `U/Y:2026`）與**第一階段更正前**的產出範例完全相同，研判係沿用舊樣板另存，並非有意改回兩格。

**建議方案**：**沿用第一階段之 `I3` 單格 `115 年 05 月`**。理由：同一系統三張報表版面應一致；業務方已於 N-04 明確要求改為單格。

**若採本建議**：範例檔 `I3`/`J3` 需視為過時，程式輸出將與範例檔版面不同（金額仍相同）。

### P-03 Balance Due 落在 `G20` 還是 `G21` ｜ 🔴 阻斷

**矛盾**：

| 來源 | Balance Due | 其他 |
| --- | --- | --- |
| 規格書 v1.0 輸出表 項次 6 | **`G21`** | 項次 7「左側合計(上)」= `O20`、項次 8「左側合計(下)」= `O21` |
| 兩份產出範例檔（實測） | `G20` **空白**、`G21` = 32,460 / 38,331 | `O20` = `O21` = 同值 |
| 範例圖檔 1 標記 ④⑤⑥ | ④ Balance Due 與標籤同列、⑤⑥ 右側上下兩格 | 與範例檔一致 |
| **第一階段已定案** | `G20` = Balance Due、`G21` = Balance Due(下)＝共保保費、`O21` = 左側合計 | `G20` 有值、`O20` 未使用 |

**分析**：這與第一階段踩過的坑同型 —— **規格書 v1.0 儲存格整體偏一列**（見第一階段 TASK K6、`TAccountCell` 之 Javadoc）。第一階段最終更正為「Balance Due 寫 `G20`（標籤 `B21` 在下一列）」。第二階段規格書同為 v1.0，且範例檔亦為舊版面，**兩者可能一起偏了一列，也可能是本報表刻意採不同配置**。

**建議方案**：**沿用第一階段更正後之配置** —— `G20` = 攤付共保賠款總額（Balance Due）、`G21` = 同值、`O21` = 同值，並比照第一階段不使用 `O20`。

**但本項風險最高**，若業務方確認範例檔版面才是對的（`G20` 空、`G21`/`O20`/`O21` 有值），則第二階段之 `TAccountCell` 需另立一組常數，不可共用第一階段的。**請務必逐格確認。**

### P-04 `O20` 是否為本報表新增之儲存格 ｜ 🔴 阻斷

**問題**：第一階段從未寫入 `O20`；第二階段規格書與範例檔都有 `O20`（左側合計(上)）。若 P-03 採「沿用第一階段配置」，`O20` 就不該寫；若採「照範例檔」，則需新增 `O20`。

**建議方案**：與 P-03 綁定，同一個答案決定兩者。

**補充疑問**：規格書把 `O20` / `O21` 都叫「左側合計」，但兩格都在**右半邊**（共保保費側）。命名疑似筆誤，請一併確認欄位名稱應為何。

### P-05 `O6`（共保保費）與 `G14`（共保管理會費）無值時寫 0 還是字串「-」 ｜ 🟡 影響驗收

**現況**：

| 來源 | 內容 |
| --- | --- |
| 規格書 v1.0 輸出表 項次 4 / 5 | 對應欄位 `O6` / `G14`，說明皆為「**無**」 |
| 兩份產出範例檔（實測） | `O6` = 字串 `'-'`、`G14` = 字串 `'-'`（**是文字，不是數值 0**） |
| **第一階段已定案** | B11 / Q-13：`-` **由會計格式自動顯示**，值寫 0 |

**建議方案**：**寫數值 `0` 並套用第一階段之會計格式** `_-* #,##0_-;\-* #,##0_-;_-* "-"??_-;_-@_-`，畫面顯示即為 `-`，與第一階段一致且可被 Excel 加總。

**差異**：若堅持寫字串 `-`，該格將無法參與任何公式運算，且與 B11 衝突。

### P-06 全部簽單年度都等於設定年時之行為 ｜ 🟡 影響驗收

**問題**：若當月理賠檔的簽單年度全部 == 設定年（例：全為 115），排除後**一份報表都不會產出**。此時：

- 算執行成功還是失敗？exit code 為何？
- 是否需在主控台／`report.json`／GUI 明確告知「本月無需產出賠款月帳單」？

**建議方案**：**視為成功（exit code 0）**，`report.json` 之產出清單為空並附說明訊息，主控台與 GUI 明確顯示「無非當年度簽單資料，未產出賠款月帳單」。理由：這是正常業務狀態，不是錯誤。
