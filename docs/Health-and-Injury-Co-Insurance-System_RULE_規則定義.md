## 2. 背景與目的

將規格書 v1.2 與業務方兩輪回覆，轉換為可實作、可測試的規則條目。

**規則編號體系**

| 前綴 | 類別 |
| --- | --- |
| `R-PATH-xx` | 路徑與檔名 |
| `R-VAL-xx` | 匯入檔檢核 |
| `R-CALC-xx` | 計算 |
| `R-OUT-xx` | 輸出寫入 |
| `R-EXC-xx` | 例外處理 |
| `R-RUN-xx` | 執行與介面 |

**證據等級**：【文件明載】／【原始碼可證】／【業務回覆】／【合理推論】

**全域約定**：所有四捨五入採 **HALF_UP**（半數進位、遠離 0）。Java 使用 `BigDecimal` + `RoundingMode.HALF_UP`，不得使用預設之 HALF_EVEN。
