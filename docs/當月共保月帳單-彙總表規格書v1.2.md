# 文件簡介

## 功能概述與需求說明

+----------------------------------------------------------------------+
| **功能概述**                                                         |
+----------------------------------------------------------------------+
| 提供當月共保月帳單-彙總表                                            |
+----------------------------------------------------------------------+
| **需求說明**                                                         |
+----------------------------------------------------------------------+
| 依匯入檔內容提供基本檢核，如檢核失敗提供錯誤訊息，後續不產出檔案。   |
|                                                                      |
| 依設定檔年月份取得對應資料產出當月共保月帳單-T字帳。                 |
|                                                                      |
| 如:115年5月，則保費匯入檔案路徑為./input/11505/VOLP11505.csv。       |
|                                                                      |
| 理賠匯入檔案路徑為./input/11505/VOLC11505.csv。                      |
|                                                                      |
| 產出檔案名稱:                                                        |
| ./output/11505/共保保費_當月共保月帳單_彙總表11505.xlsx              |
|                                                                      |
| 產出表格內容需以 ./templet/PREMIUM_SUMMARY.xlsx參照使用              |
|                                                                      |
| 讀取設定檔位子: ./config/application.xlsx                            |
|                                                                      |
| 金額需加千分號                                                       |
|                                                                      |
| 理賠匯                                                               |
| 入檔不一定會有檔案，如無理賠則相對應參數預設為0計算，表則已\[-\]顯示 |
