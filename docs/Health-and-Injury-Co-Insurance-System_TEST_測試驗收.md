定義可執行、可自動化之測試案例，作為開發完成之驗收依據。

| 項目 | 來源 |
| --- | --- |
| 標準輸入 | `docs/規格書/檔案位子範例/`（config / input / templet 皆已同步，可直接複製為測試資源） |
| 保費檔 | `VOLP11505.csv`，2,193 資料列，全為 N05 |
| 理賠檔 | `VOLC11505.csv`，14 資料列，簽單年度 113/114/115 |
| 設定檔 | `config/application.xlsx`，16 家、合計 100% |
