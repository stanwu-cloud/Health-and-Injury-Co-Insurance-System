# 文件簡介

## 功能概述與需求說明

+----------------------------------------------------------------------+
| **功能概述**                                                         |
+----------------------------------------------------------------------+
| 提供當月共保月帳單-T字帳報表                                         |
+----------------------------------------------------------------------+
| **需求說明**                                                         |
+----------------------------------------------------------------------+
| 依匯入檔內容提供基本檢核，如檢核失敗提供錯誤訊息，後續不產出檔案。   |
|                                                                      |
| 依設定檔年月份取得對應資料產出當月共保月帳單-T字帳。                 |
|                                                                      |
| 如:115年5月，則保費匯入檔案路徑為./input/11505/VOLP11505.csv。       |
|                                                                      |
| 理賠匯入檔案路徑為./input/11505/VOLC11505.csv。                      |
|                                                                      |
| 產出檔案名稱:                                                        |
| ./output/11505/共保保費_當月共保月帳單_T字帳報表11505.xlsx           |
|                                                                      |
| 產出表格內容需以 ./templet/PREMIUM_T\_ACCOUNT.xlsx參照使用           |
|                                                                      |
| 讀取設定檔位子: ./config/application.xlsx                            |
|                                                                      |
| 金額需加千分號                                                       |
|                                                                      |
| 理賠匯入檔不一定會有檔案，如無理賠則相對應參數預設為0計              |
| 算，表則已\[-\]顯示![](media/image1.png){width="2.271150481189851in" |
| height="0.645923009623797in"}                                        |
|                                                                      |
| 基本檢核不得超出字元欄位規範上限                                     |
+----------------------------------------------------------------------+
| 攤付共保賠款 =                                                       |
| 理賠匯                                                               |
| 入檔依**[設定檔]{.ul}**\[年\]取\[簽單年度\]的\[已決賠款合計\]之總和  |
|                                                                      |
| 1.  如                                                               |
| 設定年月為115年，則只取得取\[簽單年度\]為115的\[已決賠款合計\]之總和 |
|                                                                      |
| 共保管理費計算方式如下：                                             |
|                                                                      |
| 1.  先計算「保費匯入檔」中 【保費合計】 的總金額。                   |
|                                                                      |
| 2.  依各共保公                                                       |
| 司（依公司代號區分，不含中央再保）之共保成分，計算各公司應分攤保費： |
|                                                                      |
|     1.  各公司應分攤保費 = 保費匯入檔【保費合計】 ×                  |
|         共保受認成分(設定檔)                                         |
|                                                                      |
|     2.  各公司計算結果採四捨五入至整數。                             |
|                                                                      |
| 3.  將各公司（不含中央再保）應分配保費加總後                         |
| ，自保費匯入檔【保費合計】總額中扣除，其差額即為中央再保之分攤保費。 |
|                                                                      |
| 4.  以各公司（包含中央再保）之分配保費分別乘以                       |
|                                                                      |
| 5%（0.05），並四捨五入至整數，再將各公司管理費加總，即為共保管理費。 |
|                                                                      |
| 共保保費 = 保費匯入檔\[保費合計\]之總和                              |
|                                                                      |
| Balance Due(上) = 共保保費-攤付共保賠款-共保管理費\                  |
| Balance Due(下) = 共保保費                                           |

|                                                                      |
| 註3：中央再保之分攤保費與應攤配賠款採差額法計算（總額扣除其餘公司   |
