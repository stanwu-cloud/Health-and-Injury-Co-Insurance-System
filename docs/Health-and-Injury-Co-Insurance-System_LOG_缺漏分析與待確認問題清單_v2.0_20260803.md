#### N-01 設定檔共保認受成分合計為 105%，非 100%

**事證**：`config/application.xlsx` C6:C21 逐格加總結果如下。

| 群組 | 成分 | 小計 |
| --- | --- | --- |
| 壽險 8 家（L02 5%, L04 5%, L05 5%, L06 10%, L08 10%, L11 10%, L52 5%, L64 10%） | | **60%** |
| 產險 7 家（N05 6%, N06 3%, N07 2%, N08 6%, N13 5%, N14 5%, N15 6%） | | **33%** |
| 中央再保 N19 | 12% | **12%** |
| **合計** | | **105%** |

**矛盾點**：規格書（v1.0 與 v1.2 皆同）明定中央再保之分攤保費採**差額法**：
> 中央再保之分攤保費 ＝【保費合計】－各共保公司（不含中央再保）分攤保費加總

其餘 15 家合計 93%，故差額法推得中央再保之**實質成分為 7%**（100% − 93%），與設定檔記載之 12% 相差 5 個百分點。舊版範例檔中之中央再保成分亦為 **7%**。

**影響範圍**：
1. 彙總表 E22（或 E15）將顯示 12%，但該列 F、G 欄之實際金額對應的是 7%，報表**自相矛盾**。
2. 合計列 E23 = `SUM(E7:E22)` 將顯示 **105%**，報表面上明顯錯誤。
3. 若日後將中央再保改為與其他公司相同之乘算法（而非差額法），全部金額將偏差 5%。

**驗算補充**：本月樣本因中央再保採差額法，計算結果（管理費 17,505、Balance Due 205,687）**未受影響**，與範例檔完全一致。故此問題**不會被現有樣本測出**。

**建議選項**

| 選項 | 內容 |
| --- | --- |
| A | **建議**：將設定檔 C14（中央再保）由 12% 改為 **7%**，使合計為 100%。並於程式加入「成分合計須 = 100%，否則中止」之檢核 |
| B | 維持 12%，另行調降某家公司成分 5%（需業務方指定哪一家） |
| C | 維持現況，程式不檢核合計；報表 E 欄照實顯示 105% |

**需回覆**：
1. 115 年度正確之共保認受成分表為何？請確認合計為 100%。
2. 是否於程式加入「成分合計 = 100%」之啟動檢核？
3. 中央再保是否確定採**差額法**（而非 `總額 × 成分`）？
